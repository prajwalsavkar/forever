ASSETS — what to replace
========================

photo1.png … photo6.png
    Placeholder photos. Replace with your own (any name/format), then point
    the TIMELINE array in script.js at them. Portrait crops look best.

music.mp3
    Placeholder song, written for this page — nothing to license.
    Replace with your own track, keeping the filename, or change MUSIC_SRC
    in script.js. It plays when she says yes; browsers block audio before
    then. If this file is missing, the page synthesises a soft arpeggio.

cat1.svg … cat5.svg
    The cats. SVG so they stay sharp at any size. To use real cat memes
    instead, drop in your images and change the `img` paths in the CATS
    array in script.js — e.g. img: "assets/mymeme.png".

heart.svg, ring.svg
    Used for the favicon and the letters counter.
